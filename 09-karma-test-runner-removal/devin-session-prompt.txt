TASK: Migrate Karma Test Runner to Web Test Runner for Angular 20 Upgrade

PROJECT: Banking Application Test Suite Migration
PRIORITY: HIGH
ESTIMATED EFFORT: 20-40 hours

================================================================================
BACKGROUND
================================================================================

Our banking application is currently on Angular 14.2.0 and uses Karma test runner
for all unit tests. We need to upgrade to Angular 20, but Angular 20 has removed
Karma support entirely. All tests must be migrated to the new Web Test Runner.

The application has:
- 40+ test files using async patterns (fakeAsync, tick, flush, waitForAsync)
- Payment validation service tests with complex timing requirements
- Transaction list component tests with auto-refresh functionality
- Authentication guard tests with async session validation
- Account data service tests with Promise-based operations

All tests currently pass with Karma. They must continue to pass with Web Test Runner.

   ```typescript
     expect(result).toBeUndefined();
     tick(199);
     expect(result).toBeUndefined();
     tick(1);
     expect(result).toBe(true);
   }));
   ```

   Challenge: Verify tick() timing is accurate in Web Test Runner

2. BATCH ASYNC OPERATIONS

   Example from payment-validation.service.spec.ts:
   ```typescript

     service.validateBatch(payments).subscribe(r => results = r);
     flush();
     expect(results.length).toBe(3);
     expect(results[0].valid).toBe(true);
   }));
   ```

   Challenge: Ensure flush() completes all pending operations correctly

3. INTERVAL-BASED TESTS

   Example from transaction-list.component.spec.ts:
   ```typescript
   it('should set up auto-refresh', fakeAsync(() => {

     tick(500);
     tick(30000); // 30-second interval
     tick(500);
     expect(component.transactions.length).toBe(initialLoadCount);
   }));
   ```

   Challenge: Long intervals must work without timeout issues

4. PROMISE + OBSERVABLE MIX

   Example from account-data.service.spec.ts:
   ```typescript
   it('should handle create followed by retrieve', fakeAsync(() => {
     service.createAccount(data).then(created => {
       return service.getAccountById(created.id);
     }).then(retrieved => {
       retrievedAccount = retrieved;
     });
     flush();
     expect(retrievedAccount.balance).toBe(1200);
   }));
   ```

   Challenge: Mixed async patterns must resolve correctly
